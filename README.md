# Jarvis — Espace de travail business

Assistant opérationnel de **Teodor** : import d'accessoires de detailing (Chine) → revente **B2B** par contrats.

## Structure
- `fournisseurs/` — Sourcing et suivi des fournisseurs chinois.
- `prospects/` — Liste des entreprises cibles (clients B2B).
- `catalogue/` — Produits et fiches optimisées.
- `mails/` — Modèles d'e-mails (fournisseurs + prospects).

## Workflow
1. **Sourcer** un fournisseur → `fournisseurs/suivi.md`
2. **Demander** prix/MOQ par mail → `mails/fournisseur-demande.md`
3. **Sélectionner** les produits → `catalogue/produits.md`
4. **Prospecter** les clients B2B → `mails/prospect-approche.md`
5. **Suivre** les prospects → `prospects/suivi.md`
